Sub-bug #1 (found + fixed) — shaft FCalc discarded the Iterminal it must leave
------------------------------------------------------------------------------
Pascal DoDynamicMode (generator.pas:2038) `ShaftModel.FCalc(Vterminal, Iterminal)`
passes the LIVE Iterminal; the shaft model OVERWRITES it (last write), and the
trailing `IterminalUpdated`/`IterminalSolutionCount` make IntegrateStates'
ComputeIterminal reuse it — so TracePower = TerminalPowerIn(Vterminal, Iterminal)
reads the SHAFT model's currents. Rust ran the shaft model into a SCRATCH buffer
and discarded the currents (TracePower kept the USER currents). FIXED
(generator/user_model.rs::shaft_model_fcalc writes the shaft currents back).
Effect: step-1 dSpeed -75.66 -> -84.80 deg/s toward the oracle -89.24; but the
END-STATE effect is negligible (Is1 5.28e-4 unchanged) because the dominant
sub-bug #2 (below) confounds it. Pascal-cited, contained to Model=6+ShaftModel
(only wasm_gen_dyn; no corpus case), gate green.

Sub-bug #2 (OPEN) — Model=6 dynamic-current fixpoint off ~5e-4
-------------------------------------------------------------
With slip matching (2.4e-6) and zsp snapshot-proven, is1 = (v1-e1)/zsp is off
5.5e-4 from step 1 for BOTH the user and shaft model instances (they agree with
each other to ~2e-6, as in the oracle — so it is NOT a user-vs-shaft mixup). The
divergence is in the dynamic flux e1 (FInit/Integrate) or the terminal voltage v1
of the Model=6 dynamics network solve. Guest math is bit-exact to the twin
(WM.2 fixture_self_gate), so the host (dss-core Generator dynamics) must feed the
guest state that differs from what Pascal feeds the twin. Checked-and-matched:
snapshot state (1e-14), slip, Vterminal magnitude+angle, w0, Mmass, D, Pshaft.
Line-level pin needs guest-internal e1/t0p tracing, which requires rebuilding the
CONSTRAINT-FROZEN fixture .wasm (WM.4 parallel-workflow forbids touching the
fixture crates). Left as the OPEN follow-up port-bug; the dyn-deck gate stays
STRUCTURAL (numeric=false) until it is fixed (do NOT loosen any tolerance).
