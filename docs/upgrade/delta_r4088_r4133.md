**Headline:** despite the major version bump, the engine delta is compact and almost entirely a

several breaking default changes. Directories with **zero** changes: `PCElements/`, `Meters/`,
`Parser/`. The power-flow solver, Y-matrix, all PC elements (Load/Generator/PVSystem/Storage/
VSource/...), all PD elements' numerics (Line/Transformer/Capacitor/...), EnergyMeter, Monitor,
and the export/show reporting units are untouched.

## A. New element classes / new solve modes / new commands

**None.** No new DSS classes, no new solution modes, no new executive commands. `fuse.pas` moved
from `PDElements/` to `Controls/` but `TFuse` was already `class(TControlClass)` in r4088 — the
move is file organization only. The closest thing to a new command is the `batchedit ... where`
conditional syntax (classified under C).

## B. Algorithm/numerics changes in existing elements or solution loop

1. **Relay.pas** (2211 lines) — **per-phase state machine**. `FPresentState`/`FNormalState`
   become per-phase arrays (`StateArray[1..RELAYCONTROLMAXDIM=6]`); `OperationCount`, `LockedOut`,
   `ArmedForOpen/Close/Reset`, `PhaseTarget`, `RelayTarget` become per-phase arrays with an extra
   `IdxMultiPh = NPhases+1` slot for the ganged path. New `SinglePhTrip`/`SinglePhLockout`
   modes (overcurrent type only; selecting any other relay type force-disables them): per-phase
   TCC evaluation of `cBuffer^[i+CondOffset]`, per-phase `ControlQueue.Push(..., CTRL_OPEN, i, ...)`
   with the phase index carried in the proxy handle, per-phase reclose counting, and 1-ph vs 3-ph
   lockout escalation. Even in the ganged (default) path the logic changed: sampling now proceeds
   if *at least one* phase is closed (was: only when the single ganged state was CLOSE), curve
   selection uses `MaxOperatingCount` over non-locked-out phases, and `DoPendingAction` iterates
   phases individually honoring previously locked-out phases on reclose. Numeric impact: **yes**
   (trip/reclose sequencing in dynamics/time modes; ganged-only legacy cases mostly preserved but
   edge behavior around mixed phase states and lockout differs).
2. **Relay.pas `VoltageLogic`** — OV/UV trip evaluation now uses `Vmax_closed`/`Vmin_closed`
   (extrema over *closed* phases only) instead of extrema over all phases; reclose voltage check
   still uses all-phase extrema. A relay with some phases open no longer OV-trips on the voltage
   of an open phase. Numeric impact: **yes** (voltage-relay cases with partially open elements).
3. **Recloser.pas** (1432 lines) — same per-phase overhaul as Relay: per-phase states, single-phase
   trip/reclose/lockout, per-phase `OperationCount` and fast/slow curve selection by
   `MaxOperatingCount` over non-locked-out phases, per-phase control-queue pushes. Also splits the
   single `PhaseTrip`/`GroundTrip` pickup into **separate fast and slow pickups**
   (`PhFastPickup`/`PhSlowPickup`, `GndFastPickup`/`GndSlowPickup`); the legacy `PhaseTrip`/
   `GroundTrip` names now set both. Numeric impact: **yes**.
4. **Relay/Recloser sampling gate** — both now check controlled-element phase states at the top of
   `Sample` and resynchronize `FPresentState^[i]` from `ControlledElement.Closed[i]` (recloser),
   so external phase-state changes are observed. Numeric impact: yes (sequencing).

## C. New/changed properties & options & parser behavior

1. **Relay.pas** — properties 50 → **71**. Renames (old names kept as deprecated aliases):
   `Phasecurve→PhCurve`, `GroundCurve→OC_GndCurve`, `PhaseTrip→PhPickup`, `GroundTrip→OC_GndPickup`,
   `PhaseInst→PhInst`, `GroundInst→OC_GndInst`, `TDPhase→TDPh`, `TDGround→OC_TDGnd`,
   `Delay→DefiniteTimeDelay`, `Breakertime→MechanicalDelay`, `Variable→Generic_Variable`,
   `overtrip/undertrip→Generic_OverTrip/UnderTrip`, `Overvoltcurve/Undervoltcurve→
   Voltage_OVCurve/Voltage_UVCurve`. New: `SinglePhTrip`, `SinglePhLockout`, `Lock`, `Reset`
   (immediate action), `RatedCurrent`, `InterruptingRating` (both informational).
   `Normal`/`State` become per-phase **arrays** (`[closed, closed, closed]`), quoted-array or
   ganged scalar accepted. `Lock=Yes` blocks manual and internal state changes. Numeric impact:
   only via the features themselves; alias parsing is compatible.
2. **Recloser.pas** — properties 24 → **46**. Renames + aliases: `PhaseFast→PhFastCurve`,
   `PhaseDelayed→PhSlowCurve`, `GroundFast/GroundDelayed→GndFastCurve/GndSlowCurve`,
   `PhaseInst/GroundInst→PhInst/GndInst`, `Reset→ResetTime` (old name 14), `Delay→MechanicalDelay`,
   `TDPhDelayed/TDGrDelayed→TDPhSlow/TDGndSlow`, `TDGrFast→TDGndFast`. New: `PhFastPickup`,
   `GndFastPickup`, `PhSlowPickup`, `GndSlowPickup`, `SinglePhTrip`, `SinglePhLockout`, `Lock`,
   `Reset` (action), `EventLog`, `DebugTrace`, `RatedCurrent`, `InterruptingRating`; `Normal`/
   `State` per-phase arrays. Numeric impact: aliases compatible; **defaults changed** (see D).
3. **fuse.pas** — properties 10 → **12**. New `CurveMultiplier` (default 1.0) — now the divisor in
   `GetTCCTime(Cmag/CurveMultiplier)`; new `InterruptingRating` (informational). `RatedCurrent`
   **repurposed** from TCC multiplier to a purely informational continuous rating (default 1.0 →
   0.0). `FuseCurve` accepts and defaults to `"none"`. Numeric impact: **yes — breaking** (see D).
4. **SwtControl.pas** — properties 8 → **9**: new informational `RatedCurrent`. Also: setting the
   deprecated `Action` (prop 3) now triggers the same "normal-state defaults to state on first
   set" side effect as `State` (prop 7). Numeric impact: no (rating informational).
5. **TCC_Curve.pas** — `"none"` becomes a **reserved name**: creating `TCC_Curve.none` is rejected
   with error 423, and every `GetTccCurve('none')` (Fuse/Recloser/Relay) returns NIL silently
   instead of "not found". Support: `ExecHelper.DoNewCmd` now aborts (`if Result = 0 then Exit`)
   when `NewObject` fails, so the rejected object is not added to `DSSObjs`. Numeric impact: no
   (parse-time), but decks with a curve literally named "none" now error.
6. **ExecHelper.pas** — **`batchedit ... where` conditionals** (~300 new lines:
   `DoCheckConditionals`/`DoEvalConditionals`/`DoLocalizeOp_Index`): filter matched objects by
   property comparisons `>`, `<`, `>=`, `<=`, `=`, `!=` combined with `and`/`or`/`xor` before
   applying the edit (Windows/TPerlRegEx build only; FPC branch unchanged). Numeric impact: no
   for existing decks (absence of `where` follows the old path).

## D. Bug fixes / breaking default changes (same input → different result)

1. **Fuse default curve + multiplier semantics** (fuse.pas) — default `FuseCurve` changed
   `Tlink` → `NIL ("none")`, and trip time changed from `GetTCCTime(Cmag/RatedCurrent)` to
   `GetTCCTime(Cmag/CurveMultiplier)`. A legacy deck `New Fuse.F RatedCurrent=65` gets: no default
   curve → **fuse never blows**; even with a curve specified, `RatedCurrent` no longer scales it —
   `CurveMultiplier` (default 1.0) does. Numeric impact: **yes, breaking** for any legacy fuse deck.
2. **Recloser default curves removed** (Recloser.pas) — `PhaseFast` default `"A"` and
   `PhaseDelayed` default `"D"` are now `NIL`; a recloser defined without explicit curves no longer
   trips at all. Numeric impact: **yes, breaking** for decks relying on the A/D defaults.
3. **Instantaneous-trip delay no longer double-counted** (Relay + Recloser) — r4088 set inst
   `PhaseTime/GroundTime := 0.01 + Breaker_time` (relay) / `0.01 + DelayTime` (recloser) *and*
   added the same delay again at `ControlQueue.Push(... TripTime + Breaker_time/DelayTime ...)`,
   i.e. `0.01 + 2×delay`. r4133 sets inst time to bare `0.01`, delay applied once at push. Numeric
   impact: **yes** — inst trips fire earlier by one `MechanicalDelay` when the delay is nonzero.
4. **Relay `CTRL_RESET` semantics** (Relay.pas `DoPendingAction`) — r4088 called the full
   `Reset(ActorID)` (restores normal state, closes/opens element). r4133 only resets
   `OperationCount^` to 1 for closed phases (+ td21 quiet-window). A reset no longer forces the
   element back to its normal state. Numeric impact: **yes** in reclose sequences.
5. **`AllocateLoad` skips disabled meters/sensors** (ExecHelper.pas) — `CalcAllocationFactors` and
   `AllocateLoad` now check `pMeter.Enabled`/`pSensor.Enabled`. Circuits containing disabled
   EnergyMeters or Sensors get different allocation factors → different load kW after
   `AllocateLoads`. Numeric impact: **yes** (when disabled meters/sensors exist).
6. **SwtControl deprecated `Action` fix** (SwtControl.pas) — `Action=Open/Close` now sets
   `States[i]` (actual state); in r4088 it erroneously set `NormalStates[i]` and left the actual
   state untouched. Numeric impact: **yes** for decks still using `Action`.
7. **Relay/Recloser `State`/`Normal` first-set side effect** — normal state now defaults per-phase
   from present state on first `State` set (was scalar); combined with per-phase machinery, decks
   mixing `State` and later `Normal` edits can resolve differently in multi-phase cases. Numeric
   impact: edge cases only.

## E. Export/Show/report changes

1. **BatchEdit result** (ExecCommands.pas, 2 lines) — `batchedit` now sets
   `GlobalResult := 'Elements edited: N'` instead of returning the bare CmdResult. Any tooling
   reading the result string after batchedit sees new text. Numeric impact: no.
2. **Event-log wording overhaul** (Relay.pas, Recloser.pas) — trip/reclose/lockout messages
   rewritten to per-phase form (`'Phase %d opened on %s (1ph trip) & locked out (3ph lockout)'`,
   `'Phase %d closed (3ph reclosing)'`, `'Phase ALL reset (3ph reset)'`); relay targets become
   descriptive (`'Gnd Curve + Ph Curve'`, `'Ph Instantaneous'`, `'Gnd Definite Time'` instead of
   `'Ph Gnd'`); separate `Phase Target`/`Ground Target` log lines dropped; new `DebugTrace`
   `Debug Sample:` lines. Note: Relay's reset events are (upstream bug) logged as
   `'Recloser.<name>'`. Numeric impact: no (text only), but EventLog goldens/diffs change.
3. **GetPropertyValue formats** — Fuse props 5/6/12, SwtControl 9, Relay/Recloser state arrays now
   render as `[closed, closed, closed]` etc.; `Save Circuit` / `Dump` output for these classes
   changes accordingly. Numeric impact: no.
4. **Help-text-only edits** — Line.pas prop 20 (warning that `units` resets on impedance edit),
   LineSpacing.pas props 7-10 (detailed=no correction, "geometric mean distance"), AutoTrans.pas
   (normamps/emergamps marked "(Read only)"). Numeric impact: no.

## Top 15 biggest behavioral changes (ranked)

1. **Recloser per-phase rewrite + single-phase trip/reclose/lockout** (Recloser.pas, 1432 lines) — new capability + resequenced ganged logic.
2. **Relay overcurrent per-phase rewrite + single-phase trip/lockout** (Relay.pas, 2211 lines) — same machinery for type=current.
3. **Fuse `RatedCurrent` repurposed + default curve `Tlink`→`none`** — legacy fuse decks silently stop operating / stop scaling; **breaking**.
4. **Recloser default curves A/D removed** — default-constructed recloser is inert; **breaking**.
5. **Recloser fast/slow pickups split** (`PhFastPickup` vs `PhSlowPickup`, legacy `PhaseTrip` sets both) — new degree of freedom, legacy-compatible.
6. **Inst-trip delay double-count fix** (Relay + Recloser) — inst operations now fire one MechanicalDelay earlier.
7. **Relay `CTRL_RESET` no longer runs full `Reset`** — reclose/reset sequences differ.
8. **Relay `VoltageLogic` closed-phase-only OV/UV evaluation** — different trips with partially open elements.
9. **`AllocateLoad` skips disabled EnergyMeters/Sensors** — different allocation factors → different load powers.
10. **Sampling gate: continue while ≥1 phase closed** (Relay + Recloser) — protection remains active on partially open elements.
11. **Mass property rename with deprecation aliases** (Relay 50→71, Recloser 24→46 props) — parser surface, Save/Dump output.
12. **`batchedit ... where` conditionals** + `Elements edited: N` result — new command syntax.
13. **TCC curve name `none` reserved** (TCC_Curve + GetTccCurve in 3 classes + DoNewCmd abort) — decks with a curve named "none" now error.
14. **SwtControl `Action` fix** (sets actual state, not normal state) + new informational `RatedCurrent` on all four protection classes.
15. **Event-log message overhaul + `EventLog`/`DebugTrace` props on Recloser** — report-diff churn for any log-comparing harness.
